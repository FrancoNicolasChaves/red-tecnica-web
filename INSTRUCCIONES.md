# Red Técnica — Landing comercial

Este paquete contiene la landing pública de Red Técnica preparada para GitHub Pages.

## Contenido

- `index.html`: estructura y contenido comercial.
- `styles.css`: identidad visual y diseño responsive.
- `assets/cliente.png`: demostración del panel Cliente.
- `assets/administrador.png`: demostración del panel Administrador.
- `assets/tecnico.png`: demostración del panel Técnico.

## Publicación

Los archivos deben cargarse en la raíz del repositorio público `red-tecnica-web`,
conservando la carpeta `assets`.

Después de la carga:

1. Abrir **Settings**.
2. Seleccionar **Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**.
4. Seleccionar la rama `main` y la carpeta `/ (root)`.
5. Presionar **Save**.

GitHub generará una dirección pública HTTPS para el sitio.
